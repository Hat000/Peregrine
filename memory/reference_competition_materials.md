NO LOCAL_POSITION_NED/GLOBAL_POSITION_INT/ODOMETRY → self-localize REQUIRED (estimator LOAD-BEARING; Q① resolved). Control = SET_POSITION_TARGET_LOCAL_NED / SET_ATTITUDE_TARGET (<100 Hz) onto a Betaflight-style inner loop (our CTBR → SET_ATTITUDE_TARGET body-rate+thrust).
- **Wire:** MAVLink2/MAVSDK over UDP (best-effort — handle drops/reorder); chunked-JPEG video UDP:5600 (24-byte header, reassemble, drop incomplete); physics 120 Hz / commands <100 Hz / heartbeat ≥2 Hz / vision 30 Hz; align on sim_time_ns/TIMESYNC.

Scoring = time-trial, fastest VALID, ALL gates, collision ends run, 8-min cap. Round 1 simple/highlighted; **Round 2 = real 3D-SCANNED env** (~end-July) → appearance gap REAL → P5 justified.
